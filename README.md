# oddlymakessense.com

Static site for the Oddly Makes Sense YouTube channel, served by GitHub Pages.

## Add a new video

1. Put the thumbnail in `assets/` (1280x720 JPG).
2. In `index.html`, copy one `<article class="story">` block, paste it at the top of `#stories`, and change the texts and links.
3. Change the old top story's label from "THE LATEST STORY" to its own label.
4. Commit and push. The site updates in about a minute.
